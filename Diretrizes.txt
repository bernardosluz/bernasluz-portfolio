ORGANIZAÇÃO DO PROJETO — bernasluz-portfolio
=============================================

src/
├── app/                  # Rotas e layout (Next.js App Router)
│   ├── globals.css       # Design system (CSS variables, themes)
│   ├── layout.tsx        # Layout global (Navbar, Footer, ThemeProvider)
│   └── page.tsx          # Home page (single-page portfolio)
│
├── components/
│   ├── layout/           # Navbar, Footer
│   └── sections/         # Hero, About, Projects, Skills, Contact
│
├── hooks/                # ThemeProvider (dark/light)
└── lib/
    ├── config.ts         # Dados do portfólio
    └── animations.ts     # Framer Motion variants

# Regras:
- Path alias: @/ = src/
- Componentes: PascalCase
- Theming via CSS variables (--accent, --bg-primary, etc.)
- Animações via Framer Motion variants compartilhados
